# Катя о душевном — Mini App v2 (демо)

Интерактивная короткая практика с МАК-картами. Отдельный статический сайт, который можно открыть внутри Telegram через кнопку бота. Код интерфейса не требует сервера и не использует токен бота.

## Что работает

- Выбор одного из трёх запросов без интерпретации эмоционального состояния.
- Выбор одной из трёх предоставленных Кате иллюстраций.
- Три основных вопроса; четыре дополнительных доступны по желанию.
- Ответы можно не записывать и пропускать; необязательные заметки живут только в оперативной памяти вкладки и пропадают при закрытии или обновлении.
- Личная открытка 1080 × 1920 с выбранной картой и собственной фразой — формируется в браузере без загрузки текста на сервер.
- Анимации учитывают `prefers-reduced-motion`; доступен возврат на предыдущий экран.
- Telegram WebApp SDK используется только для открытия интерфейса, кнопки назад и перехода обратно к боту.
- Экран с информацией о будущей МАК-встрече и явным предупреждением, что тестовая запись/оплата ещё не открыта.
- Текстовый бот первой версии остаётся доступен как резерв.

## Безопасность и ограничения

- **Нет подключения к платёжной системе и нет сбора заявок внутри Mini App.**
- Нет аналитики поведения/отправки ответов, сохранённых на сервере профилей или AI-толкования карт.
- Любой переход к Telegram-боту ведёт в его тестовый режим. Реальные заявки сторонних пользователей там отключены.
- Стоимость 1 500 ₽ и группа 4–6 — предварительные сведения от Кати; даты и место не подтверждены.
- Макет — прототип и не является психологической диагностикой или терапией.
- Публичный HTTPS размещён на GitHub Pages. В открытом репозитории только статические файлы и согласованные для прототипа изображения; ни токенов, ни сессий Telegram, ни частных записей нет.

## Тестирование

Локальная проверка: `node --check app.js`, и сквозной браузерный тест в рабочей папке `qa_local.cjs`. Проверены мобильные размеры 390×844 и 320×640, загрузка всех изображений, последовательность вопросов, загрузка открытки и переход к экрану встречи.

## Подключение к Telegram

Настройка через официальный Bot API: `setChatMenuButton` с `web_app.url` на этот HTTPS сайт. Старая версия открывается в чате. Бот и Mini App не используют общую базу эмоциональных ответов; чувствительные заметки не передаются.

## Следующий коммерческий этап

До подключения реальных заявок: согласовать с Катей дату и место первой встречи, формат, квалификацию/коммуникацию, условия, обработку персональных данных и ответственного за заявки. Затем провести оплачиваемый пилот и измерять фактический вклад в прибыль группы, а не только просмотры.
